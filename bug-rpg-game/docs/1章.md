1章


あれから少したった。今日は王都に来ている。
王都の冒険者として活動しようと思ったからだ。
シャロンを探して、冒険者として有名になって、絶対に会いに行く。

ーーーー

王都は初めて来た。人も建物も多くて、田舎の孤児院育ちの俺には目が回りそうだった。
冒険者ギルドに登録を済ませ、さっそく依頼を探しに掲示板の前に立つ。

主人公「討伐に、採取に、、なんか地味なのばっかだな」

そう呟いたとき、広場の方から人だかりができているのに気づいた。近づいてみると、壇上に立った偉そうな身なりの男が、声を張り上げている。

重臣「魔族の王を討ちし者には、勇者の称号と、それに相応しい褒賞を与える。これは陛下の御心である!」

どよめきが広がる。周りの冒険者たちはひそひそと顔を見合わせるだけで、誰も前に出ようとしない。

主人公「魔王を倒せば、勇者、、」

頭の中に、シャロンの顔が浮かんだ。
勇者になれば、世界中の誰もが俺の名前を知ることになる。そうすればきっと、シャロンの耳にも届く。
俺は迷わず、人混みをかき分けて前に出た。

主人公「俺がやります!」

周りがざわついた。
知ったことか。今の俺には、迷ってる時間なんてないんだ。

ーーーー

少し離れた路地で衛兵たちが誰かを取り囲んでいるのが目に入った。

衛兵「その布を取れ。半魔族だろう、お前」

布で頭を隠した少年が、腕を組んだまま動じた様子もなく衛兵を見上げていた。
半魔族の少年「取ったところで、何がどう変わるんだ」

衛兵の一人が布に手をかけようとした瞬間、気づいたら足が動いていた。

主人公「待ってくれ!そいつは、俺の連れだ!」

咄嗟に出た嘘だった。衛兵たちは面倒事を避けたいのか、舌打ちをして立ち去っていく。
少年はゆっくりとこちらを振り返った。

半魔族の男「連れ、か。ずいぶん都合のいい嘘をつくじゃないか」
主人公「悪かったな、他に思いつかなかった」
半魔族の男「、、そうか」

そう言うと、男はそのまま背を向けて歩き出してしまった。

主人公「お、おい!名前くらい……」

返事はなかった。

ーーーー

王都を出て数日、俺は国境の検問所で足止めを食っていた。
魔族側の兵士が、何かを早口でまくし立ててくる。何を言っているのか、まるで分からない。
思わず剣の柄に手をかけそうになったその時。
横から割り込んできた声があった。あの時の魔族の男だ。何かを早口で兵士に返している。
兵士の態度が、少しだけ和らいだ。

主人公「……お前、この間の」
少年「マルスだ。名乗ってなかったな」
主人公「……今、何て言ってたんだ?」
マルス「お前が余所者すぎて怪しい、それだけだ。もう少し愛想よくしとけ」

マルスは小さくため息をついた。

マルス「お前、この先も同じ調子で進むつもりか?人族の土地はまだしも、魔族の領域に入ったら、お前一人じゃ言葉も分からず終わりだ」
主人公「……じゃあ、お前が案内でもしてくれるのか」
マルス「タダでとは言ってない。人族の土地じゃ、お前がいた方が動きやすい。」

俺には、断る理由がなかった。

主人公「……分かった。目的地までは、な」
マルス「ああ。それ以上は約束しない」

こうして、俺とマルスの奇妙な旅が始まった。
