# ゲーム方針の変更
## 実装の方針
* BGM,テクスチャ，導入のストーリーは別の人が担当なのでそちらができ次第統合する
* 画面の端10ピクセルくらい？に四角い枠を設置する（以降「境界」と呼ぶ）
* スタート画面から試練の間に入ったら，まず簡単なステージから始まる
* 1ステージにつき1つの新しい操作（前回まででいうところの「バグ」）にする
* 左の境界には進むことはできない（後戻りができない）．
* アイテムを見つけられずに右の境界に行った場合は1秒暗転し直前までいたステージに戻る（変更なし）
* アイテムを見つけて右の画面端に行った場合は同じく1秒程度暗転し次のステージに進む
* 要約すると，「アイテム未獲得ならループ」「アイテム獲得時は次のステージ」
* ゲームのヒントは共通してスタート地点付近に「Tips:～」のような看板を設置するものとする．Eキーで読む．

## コンセプト，概要
* 「アイテム」を獲得してボスを倒すために「試練の間」に挑戦していくアクションメイン，基本画面固定の2Dゲーム
* 最初はボスになすすべなく倒されるが，アイテムの獲得によって強くなり，最終的に倒せるようになる

## アプリ起動時
* 画面中央にタイトル・『「試練の間」に入る』・設定3つのボタンがある
* それとは別に，画面右下の方に「BOSS」アイコン（ボスっぽいアイコンと「BOSS」の文字）があり，ボスへの挑戦ができる

## 「試練の間」に入るボタン押下後（第一層）
* 基本操作がかかれた看板をスタート地点付近に置いておく（左右移動，しゃがみ，ジャンプ）
* 最初のステージは動作確認用に少しの障害物があればよい
* 境界付近に黄色い球のようなもの（以降オーブと呼ぶ）を設置し，触れたら『「はじまりのつえ」を獲得した！』という演出を出す（バグ発見/鍵発見の演出を流用）
* 「～試練の間　第一層～」と1秒ほど表示し，フェードアウト．以降ステージごとに「～試練の間　第〇層～」のように1秒ほど表示し，フェードアウトするようにする．なお，第〇層の数字は漢数字

## 第二層
* 壁抜けを実装
* スタート地点に「Tips:ボタンを組み合せると壁を抜けられるかも...?」という看板を設置
* あまり複雑なコースでなくて良い（第一層よりは複雑に）
* 抜けられる壁を2か所ほど設置し，その壁は色を変える．このときのみ，境界の色を抜けられる壁の色と同じにする
* アイテムは境界内には存在しない．実は右側の境界を壁抜けすることによって右に横スクロールがはじまり，しばらくステージを進むとオーブが現れる．よって，右側の境界にただ触れるだけでは戻されてしまう．
* 第一層と同じようにオーブに触れると『「魔導士のローブ」を獲得した！』と演出を表示
