# CLAUDE.md

## プロジェクト概要

2Dの横スクロールRPG（視点切替による疑似3Dあり）。PC向け。
普通のRPGの世界に意図的なバグを仕込み、それをプレイヤーが見つけて攻略に使うゲーム。
エンジンは Godot 4.7.2（言語は GDScript を想定）。

## ドキュメント

作業前に、関係する部分を読むこと。

- 仕様：`docs/プロンプト.md`
- シナリオ：`docs/大まかな流れ.md`、`docs/序章.md`、`docs/1章.md`

## 偽バグのルール（最重要）

- このゲームには意図的に仕込んだバグ（偽バグ）がある。偽バグは修正しない
- 意図的かどうか分からない挙動を見つけたら、直さずに質問する
- 偽バグの目印：未決定（決まり次第ここに追記する）

## 進め方

- 一度に全部を作らない。指示された範囲だけを進める
- まず方針やヒントを出す。完成コードは頼まれたときだけ書く
- レビューを頼まれたら、修正コードではなく指摘だけを返す
- 推測を含む場合はその旨を明示し、不明な点はまず質問する

- シナリオやセリフは勝手に書き換えない
- git commit は勝手にしない
