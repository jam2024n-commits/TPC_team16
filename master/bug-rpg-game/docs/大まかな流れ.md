# -世界設定
　魔法がある！
　人族、魔族、魔物が生きている世界。
　人族と魔族の混血は、人族から半魔族、魔族から半人族と呼ばれている。
　魔物は体の一部が魔力によって結晶化していて、その結晶に魔力を蓄え強くなる。
　人族は心臓を通し体全体に魔力を蓄える。
　魔族は額に二本の角を生やしており、その二本の角の根本に魔力を通し全身に蓄える。
　半魔族・半人族は一本の角があり、その一本の角の根元か心臓を通して魔力を全身に蓄える。
　魔族と半魔族・半人族は角が大きいほど強い（筋肉と同じよね） 
# -時代背景
　人族と魔族は共に魔物と闘っていたが、魔物は年々出現数が減少すると人族と魔族はお互いを攻撃し始めた。
　人族と魔族はそれぞれ建国をしようとしている。
　半魔族・半人族は、人族と魔族の両方から迫害されている。
　魔王は純粋な魔族のみで国をつくろうとし、半人族をより迫害する。
