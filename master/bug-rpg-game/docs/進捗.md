## 最終更新：2026-09-28

## 1. 今日決まったこと

詳細は CLAUDE.md の「偽バグのルール」「決定事項」を参照。

- 偽バグの目印：一覧ファイル（`data/fake_bugs.json`）を正とし、コードには `# FAKE_BUG: wall_clip` の形のタグを付ける
  - ID は名前式。JSON の項目は id、title、files、trigger、effect、requires、route、stage、hint、discovery、note
  - 一覧とタグのずれは `tools/check_fake_bugs.gd` で検査する
- ファイル名は基本的に英語にする
- 戦闘：コマンド式（ターン制）。敵の絵全体が画面に映った瞬間に暗転して戦闘画面へ
- 視点切替：別シーンへ切り替える方式。最初の例は、1人称3Dの迷路（バックルームズ風、薄暗い照明、この場面だけモノクロ）
- 解像度：320x180 を整数倍で拡大。ストレッチは `canvas_items`（文字をくっきり表示するため）。起動はフルスクリーン
- バグ発見の判定：初めて「成功」したときに発見扱い。「バグを発見！」とテントウムシの演出を出す
- バグ発見そのものはバフにしない。バフはストーリー由来にする方針（詳細は保留）
- Esc でポーズメニュー（RESUME / BUG / EXIT）。BUG は実績のようなバグ図鑑
- 迷路のゴール前の壁抜け（`maze_goal_clip`）は、ただの壁抜けなので発見数に数えない
- 倒した敵は、ステージを読み直しても復活しない
- 2D見下ろし版の迷路は削除した

## 2. 今どこまで進んでいるか

開発順の手順 1〜7 まで完了。メインシーンは `scenes/stage_tutorial.tscn`。

- 手順1：横スクロールの移動（歩く・ジャンプ・しゃがむ・ダッシュ）と当たり判定
- 手順2：偽バグ管理の土台（`BugRegistry`、一覧の検査ツール）
- 手順3：最初の偽バグ `wall_clip`（しゃがみダッシュで薄い壁を抜ける）
- 手順4：チュートリアル用ステージ。通常ルート（足場を登る）とバグルート（壁抜け）の分岐が1か所
- 手順5：バグ発見の判定と演出、ポーズメニュー
- 手順6：戦闘の最小実装（スライム1体。たたかう・ぼうぎょ・にげる）
- 手順7：視点切替
  - ステージの特定の壁を、右→左→右と3回壁抜けする（`triple_clip`）と、1人称3Dの迷路へ切り替わる
  - 迷路のゴール前の光る壁だけ、しゃがみ+ダッシュで抜けられる。しゃがめるのはゴール前だけで、しゃがむと視点が下がる
  - ゴールでカギを入手し、「カギを手に入れた！」の演出のあと暗転して、元の2Dの場所へ戻る
- 追加分
  - BUG 図鑑：発見済みはテントウムシ、未発見はシルエット。マウスを合わせると「壁抜け」「鍵のありか」または「？？？」を表示。複数ページに対応済み
  - 倒した敵の記録（`WorldState`）
- 登録済みの偽バグ：`wall_clip`、`triple_clip`、`maze_goal_clip`（最後のものは発見数に数えない）
- 確認方法：ヘッドレスのテストとスクリーンショットで確認済み。人が実際に遊んでの手触りの確認はまだ
